# 에이스원비즈니스센터 홈페이지 (리뉴얼)

㈜비즈포럼이 운영하는 에이스원비즈니스센터(영등포 에이스하이테크시티) 소개 페이지입니다.
기존 사이트의 흩어진 정보를 한 페이지 흐름으로 다시 정리했습니다.

## 구성

```
site/
├── index.html   # 페이지 전체 (구조 + 문구)
├── styles.css   # 디자인 (색상·모서리·간격은 상단 :root 변수에서 일괄 수정)
└── script.js    # 모바일 메뉴, 헤더 그림자, 스크롤 등장 효과
```

섹션 순서: 히어로 → 서비스 3종 → 공간 안내(1~5인실) → 시설 안내 → 이용 절차 → 오시는 길 → 문의

## 디자인 기준

- 흰색 베이스, 포인트 컬러 1가지(`--brand`), 회색 계열 텍스트 3단계
- 카드/버튼 모두 둥근 모서리(12~26px), 테두리는 얇게 + 그림자는 옅게
- 외부 라이브러리 없음. 폰트만 Google Fonts(Noto Sans KR)를 불러옵니다.
- 모바일에서는 메뉴가 햄버거로 접히고, 우측 하단에 전화 버튼이 뜹니다.

색을 바꾸려면 `styles.css` 맨 위 `:root`의 `--brand` 값만 수정하면 전체에 반영됩니다.

## 보기 / 배포

로컬 확인은 `site/index.html`을 브라우저로 열면 됩니다. 배포는 이 폴더 3개 파일을
호스팅(카페24, 가비아, Netlify, GitHub Pages 등)의 루트에 올리기만 하면 됩니다.

## 확인이 필요한 내용

원본 사이트(ace-1.co.kr) 접속이 이 작업 환경에서 차단되어, 아래 항목은 일반적인 문구로
작성해 두었습니다. 실제 운영 조건에 맞게 확인·수정해 주세요.

- 시설 안내 8개 항목 (인터넷, 주차, 우편·택배, 냉난방 등 실제 제공 범위)
- 1~5인실 설명 문구와 "권장 인원 / 책상 수"
- 이용 절차 4단계가 실제 계약 흐름과 맞는지
- 요금은 일부러 표기하지 않고 전화 문의로 유도했습니다. 공개할 요금표가 있으면
  `#rooms` 섹션의 `.room-meta` 자리에 넣으면 됩니다.
- 1~5인실 실사진은 준비되는 대로 `.room-plan` 안의 SVG를 `<img>` 로 교체하면 됩니다.
