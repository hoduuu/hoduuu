# 노트 창 툴바 리디자인

## 배경

노트 창(`src/renderer/note/NoteApp.tsx`)의 상단 툴바는 색상 스와치 5개, 글씨체 `<select>`, 크기 `<select>`, 고정(핀) 아이콘으로 구성되어 있다. 기본 노트 크기(240px 폭)에서 이 다섯 요소가 한 줄에 들어가지 않아 `flex-wrap`으로 두 줄로 넘어가며, 드롭다운 두 개가 시각적으로 무겁다.

사용자가 Artifact로 제시된 세 가지 방향(A: 미니멀 아이콘형, B: 정돈된 구역형, C: 라이트 리파인) 중 A의 툴바 구조와 C의 스와치 스타일을 조합하기로 결정했다.

## 요구사항

### 1. 폰트 팝오버

- 기존 글씨체 `<select>` + 크기 `<select>` 두 개를 제거하고, "Aa" 라벨의 아이콘 버튼 하나로 대체한다.
- 버튼 클릭 시 버튼 아래에 팝오버가 열린다. 팝오버 안에는:
  - 글씨체 4종(기본/명조/고정폭/손글씨) — 각각 클릭 가능한 행, 현재 선택된 항목 표시(체크 또는 강조).
  - 크기 5단계(12/14/16/18/22px) — 각각 클릭 가능한 행, 현재 선택된 항목 표시.
- 항목을 클릭하면 즉시 적용되고(기존 `handleFontFamilyChange`/`handleFontSizeChange` 재사용) 팝오버는 열린 채로 유지한다(연속으로 두 속성을 바꿀 수 있어야 하므로 자동으로 닫지 않는다).
- 팝오버 바깥을 클릭하거나 `Escape` 키를 누르면 닫힌다.
- 팝오버는 노트 창 폭(최소 240px 기본, 사용자가 더 작게 리사이즈 가능)을 벗어나지 않도록 위치를 잡는다. 노트가 팝오버보다 작아지는 극단적인 경우는 스크롤/줄바꿈으로 대응하고 별도 예외 처리는 하지 않는다.

### 2. 툴바 여백 축소

- 색상 스와치, Aa 버튼, 고정 버튼의 크기와 간격(gap/padding)을 지금보다 줄여 더 조용하고 압축된 인상을 준다.
- 기본 240px 폭에서 스와치 5개 + Aa 버튼 + 고정 버튼이 한 줄에 들어가는 것을 목표로 한다(현재는 두 줄로 줄바꿈됨). 들어가지 않으면 기존과 동일하게 `flex-wrap`으로 다음 줄로 넘어가되, 고정 버튼은 항상 보이는 위치(우측)를 유지한다 — 이전 라운드에서 고친 "고정 버튼이 창 밖으로 밀려나는" 버그를 재발시키지 않는다.

### 3. 색상 스와치 스타일

- 스와치(원형 색상 점)에 흰색 테두리를 추가한다.
- 현재 선택된 색상의 스와치에는 테두리 바깥으로 선택 상태를 나타내는 링(outline/box-shadow)을 추가해 지금보다 잘 보이게 한다.

### 4. 본문 스크롤바 스타일

- 노트 본문(`.note-app__content`) 스크롤바를 리스트 창(`.list-app__notes`)과 동일한 스타일로 맞춘다: 위아래 화살표 버튼 제거, 얇은 회색 막대(thumb)만 표시.

### 5. 태그 글자 크기

- 태그 pill(`.note-app__tag-pill`)과 태그 입력창(`.note-app__tag-input input`)의 글자 크기가 현재(12px) 잘 안 보이므로, 지금보다 살짝 키운다(12px → 13px).

### 6. 변경하지 않는 것

- 고정(핀) 아이콘의 모양과 클릭 동작은 그대로 둔다.
- 태그 입력/알약(pill) 영역의 구조(가로 배치, + 버튼으로 추가)는 이번 스펙의 범위가 아니다 — 글자 크기만 조정한다.
- 본문 textarea의 폰트/크기/줄바꿈 동작은 이번 스펙의 범위가 아니다 — 스크롤바 스타일만 조정한다.

## 구현 메모

- 팝오버는 외부 라이브러리 없이 순수 React 상태(`useState`)로 열림/닫힘을 관리하고, `useEffect`로 문서 클릭/`keydown` 리스너를 등록해 바깥 클릭·Escape를 처리한다(기존 코드베이스에 이미 동일 패턴이 없으므로 새로 작성).
- `NoteApp.css`의 `.note-app__font-select` 관련 스타일은 제거하고 `.note-app__font-toggle`(Aa 버튼), `.note-app__font-popover`(팝오버 컨테이너), `.note-app__font-option`(팝오버 안의 각 행) 등 새 클래스로 대체한다.
- 기존 `FONT_FAMILIES`, `FONT_SIZES` 상수와 `handleFontFamilyChange`/`handleFontSizeChange` 핸들러는 그대로 재사용한다.

## 테스트

- 이 변경은 순수 UI/스타일 변경이라 새로운 단위 테스트 대상 로직은 없다(기존 `noteUtils` 테스트는 영향 없음).
- `npm run typecheck`, `npm test`, `npm run build`로 회귀가 없는지 확인한다.
- Xvfb + CDP로 노트 창을 띄워 Aa 팝오버 열기/항목 선택/바깥 클릭 닫힘, 스와치 선택 링, 기본 폭에서 툴바가 한 줄에 들어가는지, 스크롤바 스타일, 태그 글자 크기를 스크린샷으로 확인한다.
